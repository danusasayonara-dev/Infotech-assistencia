INFOTECH ASSISTÊNCIA — VERSÃO COMPLETA OFFLINE (BASE V2)

Esta versão mantém a identidade visual/layout da V2 e acrescenta recursos de gestão:
- Orçamentos com cadastro, edição e exclusão.
- Botões de editar/excluir nos cadastros principais.
- Seleção de cliente previamente cadastrado para abrir OS e orçamento.
- Painel com entradas, saídas, resultado estimado, OS abertas/prontas e alerta de estoque baixo.
- Busca rápida por cliente, OS, orçamento, venda e produto.
- Campos de entrega/Uber na OS, com identificação de quem pagou.
- Comprovante com prazo de garantia e vencimento por dias corridos: 30, 90, 180 ou 365 dias.
- Salvamento local automático e cópia de segurança local, além do backup JSON manual já existente.
- Exclusão de cliente com histórico vinculado é bloqueada para preservar o histórico.
- Edição de lançamentos financeiros refaz os lançamentos vinculados para reduzir duplicidades.

LIMITAÇÕES IMPORTANTES
- Esta é uma aplicação estática/offline-first. Login individual, sincronização entre dispositivos e backup automático em nuvem NÃO podem ser ativados sem configurar um backend (por exemplo, Supabase/Firebase), criar credenciais privadas e regras de segurança. Não publique dados de clientes em repositório público.
- A cópia automática é local no mesmo navegador/dispositivo; não substitui backup externo.
- A edição de registros usa caixas de diálogo do navegador para alterar campos. Recomenda-se conferir valores e relatórios antes de usar no caixa real.
- O cadastro não possui integração bancária, emissão fiscal ou envio automático de mensagens.
- Excluir um cliente que possua OS/vendas/orçamentos vinculados é bloqueado para não apagar o histórico.
- Antes de substituir sua versão em uso, exporte um backup JSON e teste a nova versão com registros fictícios.

INSTALAÇÃO
1. Baixe e descompacte o ZIP.
2. Faça backup JSON da versão atual.
3. Envie o conteúdo da pasta infotech_assistencia_app para a raiz do repositório GitHub Pages, substituindo os arquivos antigos.
4. Aguarde a publicação. No iPhone, feche o app e abra novamente; se necessário, remova o app da tela inicial e adicione o site novamente.
